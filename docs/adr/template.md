## Consecuencias

**Positivas:** qué habilita o simplifica.

**Negativas / coste aceptado:** qué empeora, qué deuda se contrae. Sé honesto —
un ADR sin costes es propaganda, no ingeniería.

**Cuándo revisar:** la condición objetiva que invalidaría esta decisión
(ej. "cuando la API corra más de una réplica").
